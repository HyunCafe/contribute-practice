# GitHub and Git: A beginner's glossary

| Term | Plain-language meaning |
| --- | --- |
| Repository (repo) | A project containing files and often the history of their changes. |
| Git | A tool for tracking changes and working with versions of files. |
| GitHub | A website and platform for hosting repositories and collaborating. Git and GitHub are not the same thing. |
| Fork | A copy of someone else's repository in your GitHub account. |
| Clone | Download a repository and its Git history to your computer. |
| Branch | A separate line of changes that can be reviewed before merging. |
| Commit | A recorded snapshot of a change, with a message explaining it. |
| Push | Send local commits to a remote repository, often your own fork on GitHub. |
| Pull request (PR) | A proposal to merge changes from one branch into another. |
| Base | The destination repository and branch for a pull request. |
| Head | The branch containing proposed changes. |
| Review | Feedback from a maintainer or another collaborator. |
| Merge | Incorporate approved changes into the destination branch. |
| `origin` | The default nickname for the remote repository you cloned from. If you cloned your fork, `origin` is normally your fork. |
| `upstream` | A conventional nickname for the original repository when your local clone is linked to a fork. It's optional for this exercise. |
| Markdown | Lightweight formatting used in `.md` files, like `README.md`. |
| Default branch | A repository's primary branch, often `main`. Don't assume every project uses the same name. |
| Issue | A place to report a problem, propose an improvement, or ask a question. |

For more depth, use [GitHub's documentation](https://docs.github.com/en/get-started/start-your-journey) and the free [Pro Git book](https://git-scm.com/book/en/v2).
